# VEXORA

Código completo do site em HTML, CSS e JavaScript. Inclui a logo transparente, o WhatsApp comercial, o portfólio, as demonstrações e as páginas legais da versão de 23 de novembro de 2026.

## Colocar no repositório

Extraia o ZIP e envie todo o conteúdo da pasta para a raiz do seu repositório, mantendo os nomes e as pastas. Mantenha o index.html na raiz. Envie também as pastas css/, js/, assets/ e demos/.

## Editar no VS Code

Abra a pasta extraída no VS Code. Para testar, execute `python -m http.server 8000` no terminal, ou `py -m http.server 8000` no Windows, e abra http://localhost:8000.

## Arquivos principais

| Arquivo | O que editar |
| --- | --- |
| index.html | Textos, navegação e estrutura da página inicial |
| css/base.css | Layout e componentes compartilhados |
| css/tema.css | Cores, fontes, logo e identidade visual |
| css/portfolio.css | Galeria e prévia das demonstrações |
| css/legal.css | Estilo das páginas legais |
| js/config.js | WhatsApp comercial |
| js/dados/planos.js | Preços, benefícios e comparação de planos |
| js/planos.js | Exibição dos planos e da comparação |
| js/orcamento.js | Formulário, resumo e envio do orçamento |
| js/dados/projetos.js | Textos, imagens e endereços dos projetos |
| js/portfolio.js | Navegação do portfólio e abertura das demos |
| js/animacoes.js | Animações ao rolar a página |
| privacidade.html, termos.html e atendimento.html | Conteúdo das páginas legais |
| assets/ | Imagens e logos |
| demos/ | Páginas das demos, com seus próprios diretórios css/ e js/ |

As demos de versões anteriores continuam disponíveis nos mesmos endereços. Seus arquivos de estilo e scripts estão identificados como legado.

## Publicação e operação

O repositório armazena os arquivos. A publicação depende da hospedagem escolhida. O site é estático e dispensa instalação de pacotes ou etapa de build.

A política de privacidade descreve a hospedagem atual no ChatGPT Sites. Antes de publicar em outro provedor, atualize a seção de hospedagem e a política vinculada. Complete também a identificação legal do prestador, endereço e e-mail, que continuam sinalizados como pendentes. A rotina comercial e os contratos exigem revisão antes das vendas reais.
