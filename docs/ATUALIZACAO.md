# Substituição da estrutura anterior

Esta entrega reorganiza todos os arquivos do projeto. É uma atualização completa, com novos caminhos de CSS, JavaScript e imagens.

## Publicar

1. Guarde uma cópia da versão anterior.
2. Extraia este ZIP em uma pasta vazia, preservando a estrutura.
3. Envie os arquivos e pastas novos ao diretório publicado do site. O `index.html` deve ficar na raiz desse diretório.
4. Confira se `assets/css`, `assets/js`, `assets/images` e `demos` foram enviados.
5. Após a publicação, abra as páginas e as demos para conferir o carregamento.

Os caminhos das páginas principais e das demos foram preservados. Os arquivos antigos de CSS e JavaScript que ficavam soltos na raiz foram transferidos para `assets/`. As imagens passaram de `assets/` para `assets/images/`.

Se o envio ao repositório apenas acrescentar os novos arquivos, as cópias antigas podem continuar ali. A nova página usa os novos caminhos. Depois de validar a publicação e guardar a versão anterior, remova somente os arquivos antigos que não são mais referenciados. Preserve qualquer arquivo próprio de domínio, redirecionamento ou configuração da hospedagem que você tenha criado fora deste pacote.

## Arquivos antigos preservados

- `demos/brasa/index.html`, `demos/flora/index.html` e `demos/forma/index.html` continuam disponíveis.
- Os catálogos dessas demos ficam em `assets/js/data/legacy-products.js`.
- Seus estilos e comportamentos ficam nas pastas `legacy` de CSS e JavaScript.
- O código histórico da primeira estrutura foi identificado como `site-original.js`, `site-original.css` e `portfolio-original.css` e permanece separado para consulta.

## O que esta entrega faz

Organiza e formata o código, separa configurações e dados, centraliza os valores dos planos e preserva textos, marca, imagens, páginas legais e demonstrações. Não publica o site automaticamente nem altera suas contas, domínio ou hospedagem.
